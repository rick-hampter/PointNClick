This ReadMe is different to the one found in the main branch.
This ReadMe contains the solutions to all puzzles in the game and all of the controls in the game.

Press I to toggle debug mode. Debug mode shows the game's values on the screen in pink.
Debug mode allows for the revisiting of any scene in the game using number keys and the Menu with M.
DO NOT PLAY THE GAME IN DEBUG MODE.

After pressing Play, use the key under the rock to open the front door.
Upon entering the Hallway, click the coat on the rack to get the first key (the orange key) needed to unlock the door in the basement.
Go through the door in the hallway to enter the Foyer and use the key on the door.
Go up the stairs until you get to the Landing at the top of the stairs. Take the pink key from the globe.

Enter the Painting Room on the left.
Turn on the light switch on the left side of the room. Slide the painting over to reveal the green key.
Unlock the final lock and enter the door.

Enjoy the music.



Enjoy Playing!
